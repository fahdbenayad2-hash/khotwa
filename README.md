# خُطوة — KHOTWA v1.1

موقع شخصي عربي لتنظيم المهام والمشاريع وجلسات التركيز، بتصميم هادئ دون ضغط أو عقوبات على الانقطاع.

**الموقع:** https://fahdbenayad2-hash.github.io/khotwa/

## الجديد في v1.1
- زر **ابدأ 5 دقائق** على المهمة الأساسية يبدأ التركيز بنقرة واحدة، مع بقاء خيارات المدة.
- إضافة مهمة أساسية ومهمتين مساعدتين في «اليوم»؛ المهمة الرابعة تبقى محفوظة في Inbox.
- تذكير غير إجباري بتصدير نسخة احتياطية كل 14 يوماً عندما تكون هناك بيانات أقدم.
- نسخ احتياطية **v2** بحقل `schemaVersion`، مع استمرار دعم استيراد نسخ **v1**.
- فحص أقوى عند الاستيراد وتنبيه قبل استبدال البيانات مع محاولة تنزيل نسخة من البيانات الحالية.
- ترقية غير مدمّرة إلى IndexedDB v2 مع فهارس جديدة.
- إصلاح بعض حالات تعذر الكتابة في localStorage، وتحسين تقدير زمن المؤقت أثناء الجلسة.
- تحديث Service Worker ومسح نسخ الكاش القديمة.

## الخصوصية
بيانات المهام محفوظة محلياً في نفس المتصفح، **ولا يوجد حساب ولا مزامنة تلقائية بين الأجهزة**. لا ترفع ملفات النسخ الاحتياطي الحقيقية إلى GitHub، لأن المستودع عام.

## التشغيل والنشر
هذا موقع ثابت؛ افتح `index.html` أو انشر ملفات الجذر من `main` باستخدام GitHub Pages. يلزم HTTPS للعمل دون اتصال عبر Service Worker. بعد النشر أعد فتح الصفحة متصلاً بالشبكة لتثبيت التحديث الجديد.

## الاختبارات
`tests/test_smoke.py` يحتوي اختبارات Playwright للمهام اليومية، التركيز بنقرة واحدة، الاستراحة والاستمرار، تصدير البيانات، والاستيراد المتوافق مع v1. يتطلب Python وPlaywright وChromium. الاختبارات تستخدم تخزيناً مؤقتاً معزولاً؛ **لا تعتبر بديلاً لاختبار ترقية IndexedDB على متصفح فعلي يحتوي بيانات سابقة**.
