# خُطوة — KHOTWA

موقع شخصي عربي لتنظيم المهمة الأساسية لليوم، المشاريع، جلسات التركيز، والعادات دون تعقيد أو عقوبات على أيام الانقطاع.

## فتح التطبيق

بعد إكمال نشر GitHub Pages:

https://fahdbenayad2-hash.github.io/khotwa/

## GitHub Pages

This is a static website. Publish from branch `main`, directory `/ (root)`, in **Settings → Pages → Build and deployment**. The home page is `index.html`; `.nojekyll` disables Jekyll processing. Updates to `main` trigger publication when GitHub Pages is enabled.

## الخصوصية

- بياناتك تحفظ محلياً في المتصفح ولا تتزامن بين الأجهزة.
- لا ترفع نسخك الاحتياطية المحتوية على مهامك الشخصية إلى مستودع GitHub العام.
- يمكنك تصدير نسخة احتياطية من داخل التطبيق.

## Getting started

Open `index.html` in your browser or deploy this repository as static content.
